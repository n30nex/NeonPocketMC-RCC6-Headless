# NeonPocketMC RCC6 Headless 1.0 RC2

Experimental screenless companion firmware for the Heltec RadioCore RCC6-L62/SX1262.

- Separate BLE, native USB/serial, and Wi-Fi Web/TCP images
- BLE default pairing PIN `123456`
- 350 contacts, 40 channels, and 256 queued companion frames
- Normal app-only images at `0x10000`
- Recovery images reset NVS while preserving the later MeshCore SPIFFS data partition

## Location-advert correction

The Web location action now confirms whether saved browser coordinates will be included in MeshCore adverts and persists that existing MeshCore policy. Older clients that omit the new choice preserve the prior policy. BLE and native USB behavior is unchanged and regression-built.

> **Trusted-LAN warning:** TCP/5000 exposes the complete companion/admin protocol. Use the Web image only on a trusted private network.

Use only assets from this release and verify them with `SHA256SUMS.txt` before flashing.
