# NeonPocketMC RCC6 Headless 1.0 RC1

First experimental screenless companion release for the Heltec RadioCore RCC6-L62/SX1262.

- Three separate images: BLE, native USB/serial, and Wi-Fi Web/TCP
- BLE default pairing PIN `123456`
- Wi-Fi setup credentials and assigned LAN IP printed on the 115200-baud USB console
- Standard MeshCore companion protocol; no custom phone application required
- 350 contacts, 40 channels, and 256 queued companion frames
- Normal app-only image at `0x10000`
- Recovery images reset NVS but preserve the later MeshCore SPIFFS data partition
- No display, framebuffer, repeater, observer, or room-server path

Use only assets from the matching GitHub release and verify them with `SHA256SUMS.txt` before flashing.
